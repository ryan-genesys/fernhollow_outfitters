Before you present

  • Serve the site over http or https. The Messenger won’t load from a file opened directly on disk.
  • If the deployment restricts domains, add the host you’re serving from.
  • Log in to Genesys Cloud as an agent on the Training queue and go On Queue.
  • Open the browser console to watch the tracking events the site records.

Scenarios

1. Order status, handled by the bot

  1. Open the Messenger from any page and type “Where’s my order?”
  2. Give order FH-100245 and email alex.rivera@example.com.
  3. Fern replies that it shipped with UPS and arrives Tuesday. No agent needed.

2. Delayed order, escalated to an agent

  1. Ask Fern about order FH-100517, jordan.lee@example.com.
  2. Fern sees the order is delayed, apologizes, and transfers to the Training queue.
  3. Point out that the agent sees the whole bot conversation, so they don’t have to ask for the order number again.

3. Start a return

  1. On the Returns page, choose “Start a return with Fern.”
  2. Ask Fern to start a return with FH-100422, sam.okafor@example.com. The order qualifies and Fern confirms the label.
  3. Repeat with FH-100609, casey.nguyen@example.com. It’s past 60 days, so Fern offers the warranty team.

4. Product question, routed in context

  1. Open the Trail Shell Jacket and choose “Chat with a specialist.”
  2. The conversation starts with entryPoint = product-question and the page title, so the flow skips Fern, greets the customer about that product, and routes to Training at priority 3 with the product name in routingReason.

5. Digital User Tracking (next phase)

  1. Browse Jackets, open a product, add it to the cart, and open the cart.
  2. Start a chat. Once tracking is on, the agent sees that journey alongside the conversation.

Entry points

Every chat button sets entryPoint, pageTitle, and pagePath as custom attributes before opening the Messenger.

entryPointWhere it’s set
home-order-helpHome page, “Chat with Fern”
product-questionProduct pages, “Chat with a specialist”
cart-helpCart summary
order-statusOrder status page, Fern panel
order-delayedOrder status result for a delayed order
return-outside-windowOrder status result past the return window
returnsReturns page
help-centerHelp center chat card
footerFooter “Chat with us”

Chats started from the Messenger’s own launcher have no entryPoint; treat that as the general menu.
